# Классификатор обращений с LLM

Python 3.10+. Для каждого обращения скрипт печатает категорию
«справка / жалоба / другое» и один черновик ответа на русском.
В комплекте — пять исходных обращений в `messages.txt`.

## Запуск

```bash
python -m pip install -r requirements.txt
python classifier.py
```

На macOS/Linux при необходимости используйте `python3` вместо `python`.
Запускайте в обычном терминале. Скрипт сам спросит:

1. Путь к файлу: Enter выбирает `messages.txt` рядом со скриптом.
2. API-ключ OpenAI: ввод скрыт, ключ не сохраняется в файлы.
3. Модель: Enter выбирает `gpt-4o-mini`.

Переменные окружения и аргументы командной строки не нужны.
В файле — одно обращение на строку, кодировка UTF-8; номера `1)` необязательны.
Для новых примеров отредактируйте файл или укажите другой путь.
Обращения отправляются в OpenAI API; нужен ключ с доступом и доступная квота.
API оплачивается отдельно от подписки ChatGPT.

## Ошибки и результат

Неверный путь, пустой файл, кодировка или некорректный ввод вызывают
повторный вопрос. Существование модели и действительность ключа
проверяются API при обработке первого обращения.
При ошибке API доступны: повторить, заменить ключ, заменить модель,
пропустить обращение или выйти. После замены повторяется текущее обращение;
уже обработанные не отправляются заново. Автоматические повторы отключены,
тайм-аут сетевой операции — 30 секунд. Ctrl+C завершает работу без traceback.

LLM учитывает смысл и отрицания; формат проверяется через Pydantic.
«Справка» означает информационный запрос, «другое» включает просьбу
выполнить действие. При смешанных темах реальная жалоба имеет приоритет.
Ожидаемые категории пяти примеров: справка, жалоба, другое, жалоба, справка.
В конце выводится число успешно обработанных обращений.

Проверены локальные сценарии неверного ввода и восстановления после ошибок
с имитацией API. Реальные ответы LLM не проверены: API-ключ не предоставлен.
Правильный формат не гарантирует точность; черновики требуют проверки.
